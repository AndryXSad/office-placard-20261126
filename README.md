A one-line museum placard for an ordinary office object, written as if it were an ancient artifact: the office microwave recast as an "Offering Chamber" of a lost break-room cult — catalogue date, material, and donor included, with the god returning the priests' cold sacrifices merely lukewarm.

Entry for make.fun's "Office Artifacts: The One-Line Placard Contest" bounty. A dry-witted curator judge compares placards two at a time and picks the more inventive and funnier one; a single winner takes the $2 reward.

## Run it

```sh
python3 main.py
```

Writes the placard (146 characters, one line) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic: one fixed string, no clock, no randomness, no network. Standard library only.
